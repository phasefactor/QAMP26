# QAMP 2026 Project
## Modernizing QGSS and Quantum Challenge Notebooks

This project's goal is to update the lab notebooks from previous iterations of Qiskit Global Summer School and Quantum Challenge events to the current Qiskit API.

The lab notebooks from previous Qiskit Global Summer School and Quantum Challenge events are great educational resources and represent many hours of effort from the authors and contributors. However, most of them no longer run properly in modern Qiskit environments. This prevents the community from using these notebooks as learning materials, and causes confusion for newcomers to Qiskit trying to use the older materials.
